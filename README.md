# Creative Logo Makers

Modern Next.js design marketplace for **Creative Logo Makers** — logos, web, packaging, and more at [creativelogomakers.com](https://creativelogomakers.com).

## Stack

- Next.js 16 (App Router)
- TypeScript
- Tailwind CSS v4
- Syne + Manrope typography

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Pages

| Route | Purpose |
|-------|---------|
| `/` | Home |
| `/categories` | All design services |
| `/categories/[slug]` | Category detail + packages |
| `/pricing` | Contests, projects, Studio packages |
| `/contests` | Design contests |
| `/projects` | 1-to-1 projects |
| `/studio` | Full-service branding |
| `/designers` | Find a designer |
| `/inspiration` | Portfolio inspiration |
| `/how-it-works` | Process |
| `/logo-maker` | Free interactive logo maker |
| `/get-started` | Brief form |
| `/about` · `/contact` | Company |

## Brand direction

Ink + acid lime, exaggerated minimalism, oversized display type — built to feel premium and stop the scroll.
